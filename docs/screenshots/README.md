# Screenshots

This directory contains visual assets for the README and documentation.

## preview.png

A screenshot or GIF demonstrating the interactive dry run viewer in action.

**To add a screenshot:**

1. Navigate to https://visucode.vercel.app
2. Open any problem (e.g., "Two Sum" or "Binary Search")
3. Take a screenshot showing the dry run viewer with:
   - Code editor on the left
   - Array visualizer with pointers
   - Variable inspector
   - Step controller
4. Save as `preview.png` in this directory
5. Recommended dimensions: 1920x1080 or 2560x1440
6. Compress with tools like TinyPNG to keep file size under 500KB
